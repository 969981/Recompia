## 功能

### 一起游玩（Link Play）
- **拜访朋友的岛屿，或邀请朋友来到你的岛屿**，可通过同一 Wi-Fi 或互联网进行。
- **与使用 [上游项目](https://github.com/xFractals/pokopia-native)的玩家跨平台联机**。
- 在启动器的 **Link Play** 页面中设置，无需编辑文件。
- 分步指南：[一起游玩](#playing-together)。

### 导入你的存档
- **已经在使用 Eden 或 Ryujinx？** 在 **Settings**（设置）中点击一个按钮，即可找到并导入你的存档。模拟器中的原存档不会被改动。
- **存档在其他位置？** 选择存档所在的文件夹，即其中包含 `B00`、`G00` 和 `S00` 的文件夹。
- **你当前的存档绝不会被删除。** 程序会先将其保留为备份文件夹。
- 如果存档无法写入，例如磁盘已满、OneDrive 或杀毒软件占用文件，程序会保留最近一次完好的存档，并在游戏中提示你。

### 简单的设置流程
- **直接使用你的游戏转储：** 可以是一个文件夹（其中包含 `base` 和 `updates`），也可以是一个 `.nup` 或 `.nx` 文件。
- **转储有问题时会显示清楚的提示：** 游戏版本错误、缺少更新，或文件在复制时损坏。启动器会告诉你如何处理。
- **启动前检查：** 磁盘空间是否充足、显卡驱动是否正常工作、内存是否足够。
- **Use fewer cores**（使用较少核心）可让电脑在构建期间保持可用。你可以暂停，之后再继续。
- **更新很快：** 只重新构建有变化的部分。
- 新版本发布时，启动器会通知你。

### 控制方式
- **支持各种手柄：** Xbox、PlayStation、Switch Pro 等，支持震动和体感。按钮默认采用 Switch 布局。
- **键盘和鼠标。** 鼠标也可用于菜单：点击确认高亮的项目；滚动或使用方向键移动高亮。
- 在 F1 的 **Controls**（控制）页面中**更改任意按钮**。
- **屏幕上的按钮图标会匹配你正在使用的设备：** 键盘、Xbox、PlayStation、Steam Controller 或 Switch。
- **输入名字**时可使用手柄、鼠标或键盘。
- **无需 Alt+F4 即可退出：** 按住 Select 和 Start（Xbox 手柄上的 View 和 Menu），或使用 F1 中的 **Quit game**。
- **用手柄打开 F1 菜单：** 同时按下两个摇杆（L3 + R3）；可在 `controls.ini` 的 `[overlay] pad` 中更改或关闭（`none` = 关闭）。它不能与退出组合键相同。

### Steam Deck 和掌机
- 可识别 Steam Deck、Legion Go S 和其他掌机：屏幕上保留手柄图标，画面尺寸适配屏幕。
- 16:10 屏幕会铺满画面，没有黑边。
- 在 SteamOS 上原生运行，并带有掌机优化（玩家实测在 Steam Deck 上约为 26 至 53 fps，在 Legion Go S 上为 55 至 75 fps）。
- 启动器也可在 Linux 和 SteamOS 上运行：请参阅 [Linux、SteamOS 和 Steam Deck](#linux-steamos-and-the-steam-deck)。

### Android 手机和平板
- **一个 APK 适用于 arm64 手机和平板**（Android 11 或更高版本，Vulkan 1.3）。它不包含任何游戏文件：游戏会在手机上根据你自己的转储构建，无需电脑。
- **触控操作或手柄。** 连接 USB 或蓝牙手柄后，触控按键会自动隐藏。在屏幕空白处拖动即可转动视角。
- **已为你选好手机默认设置：** 首次启动时，分辨率、帧率上限和内存设置会适配手机的 GPU 和内存。你可以在应用的 **Settings** 中更改。
- **合作模式和 Link Play** 也可在手机上使用：请参阅[一起游玩](#playing-together)。
- 设置和游玩：请参阅 [Android](#android)。

### 画面
- **可使用任意分辨率游玩**，包括 4K 及更高。运行缓慢时，降低 **Render scale**（渲染比例）。
- **画质预设**（Switch 2、High、Ultra）可设置可视距离和纹理清晰度。
- 在 HDR 屏幕上支持 **HDR**。
- **窗口、无边框或全屏。** 可选择显示器、限制帧率、显示 FPS 计数器。游玩时按 Alt+Enter 切换模式。
- **升频器：** 支持 FSR 1 和 NVIDIA Image Scaling。
- **已有 FSR 3 和 DLSS / DLAA，但目前效果不佳**，需要重新调整。暂时请保持关闭。

### 游戏内设置
在游戏中按 **F1**，即可更改画面、控制和声音设置（音量、输出设备、窗口处于后台时静音）。大多数更改会立即生效。

在 Android 上，打开游戏的暂停菜单，然后选择 **Settings**：手机的显示设置位于 **Display** 和 **Performance** 选项卡中（请参阅 [Android 设置](#android-settings)）。

## 快速开始

1. 从[最新发布版本](https://github.com/Dittobyte/Recompia/releases/latest)下载 `Recompia-<version>-windows-x64.zip`，并解压到任意位置。
2. 运行 `Recompia.exe`。如果 SmartScreen 发出警告，请选择 **More info → Run anyway**。选择你的转储文件夹，然后按 **Set up**（设置）：程序会在你的电脑上编译游戏（约 7 分钟），再构建着色器缓存（1 至 2 小时，可以暂停并稍后继续）。
3. 按 **Play**（开始游戏）。

在游戏中按 F1 打开设置。按鼠标中键可切换 Joy-Con 2 鼠标模式（指向并点击即可放置和破坏方块）。

### Linux、SteamOS 和 Steam Deck

1. 从[最新发布版本](https://github.com/Dittobyte/Recompia/releases/latest)下载 `Recompia-<version>-linux-x86_64.tar.gz`，并解压到任意位置，例如你的主目录。
2. 运行该文件夹中的 `Recompia.AppImage`（双击它，或在终端中运行 `./Recompia.AppImage`）。选择你的转储文件夹，然后按 **Set up**：首次运行时会下载构建工具（Python 和 Zig，约 100 MB）、编译游戏，再构建着色器缓存。你可以暂停并稍后继续。
3. 按 **Play**。

所有程序都不通过 Proton 或 Wine 运行：启动器、游戏、着色器翻译器和构建工具都是原生 Linux 程序。

如果在没有 FUSE 的系统上 `Recompia.AppImage` 无法启动，请运行 `./Recompia.AppImage --appimage-extract-and-run`。

要从 Steam 启动（Deck 上的游戏模式）：把启动器添加到 Steam，可以在启动器的设置中（Steam，Add to Steam），也可以在桌面模式中用 **Add a Non-Steam Game** 选择 `Recompia.AppImage`，并让启动选项留空。该快捷方式会打开启动器，由它检查更新；然后点击“开始游戏”。更多详情和测试情况请参阅 [launcher/README.md](../../launcher/README.md#linux-steamos-the-steam-deck-bazzite-other-distributions)。

### Android

**你需要：**
- 一台运行 Android 11 或更高版本、支持 Vulkan 1.3 的 arm64 手机或平板。已在 Snapdragon 8 Gen 3（Adreno 750）上测试。内置的 Mesa Turnip 驱动支持 Adreno 6xx、7xx 和 8xx GPU（Snapdragon 8 Gen 1 至 8 Gen 3 以及 8 Elite）。建议 12 GB 内存；内存较少的手机会使用[低内存配置](#common-problems)。使用其他 GPU（Exynos、Mali 等）的手机会使用手机自带的驱动和保守的默认设置，测试也少得多。
- 你自己解密的游戏转储，以文件夹形式提供：与电脑版启动器使用的文件夹相同（`base` 和 `updates`，或 `exefs` 和 `romfs`）。约 7.3 GB。应用绝不会下载游戏数据，也不包含任何游戏文件。
- 可用空间：游戏文件约 7.3 GB，构建游戏期间 2.6 GB（最终保留 0.6 GB），着色器 6.6 GB。在手机上翻译着色器时，开始时需要 12 GB 可用空间。

**设置：**
1. 从[最新发布版本](https://github.com/Dittobyte/Recompia/releases/latest)下载 `Recompia-<version>-android-arm64.apk`，并在手机上打开。如果 Android 询问，请允许你的浏览器或文件管理器安装应用。
2. 将转储复制到手机：用 USB 线将手机连接到电脑，在手机上选择 **File transfer**，然后将整个文件夹复制到手机的 `Download` 文件夹中。也可以使用 microSD 卡或 U 盘。请以二进制模式复制：文本模式的 FTP 复制会损坏文件。
3. 打开 Recompia 并按 **Get started**。在 **Storage access** 页面按 **Allow storage access**，并允许访问所有文件：应用会在原位置读取你的转储，并将自己的数据保存在 `/sdcard/Recompia` 中。
4. 在 **Game files** 页面，位于 `Download` 或手机存储顶层的转储会列在 **Found on this phone** 下。否则请按 **Choose a folder** 并选择它。文件会在原位置检查和读取，不会复制任何内容。（如果应用无法在原位置读取某个文件夹，会改为提供复制到 `/sdcard/Recompia/dump` 的选项。）
5. 在 **Build** 页面按 **Start building**。游戏会在手机上根据你的文件构建：在充电中的 Snapdragon 8 Gen 3 手机上约需 45 分钟，较慢或发热的手机上会更久。请保持手机接通电源并放在凉爽处。关闭应用后构建仍会继续，**Pause** 会保留已完成的工作。
6. 在使用 Adreno GPU 的手机上，接下来是 **Graphics driver** 步骤：按 **Use the included Turnip driver**。手机自带的驱动在此游戏中会显示黑屏。
7. 在 **Shaders** 页面按 **Translate on this phone**（在同一台手机上约需 1.5 至 2 小时，可以暂停）。或者，如果你在电脑上装有 Recompia，可将其 `shader_cache` 文件夹（不含其中的 `corpus` 文件夹）复制到 `/sdcard/Recompia/shader_cache`，然后按 **Import a shader cache from a PC install**：这样可以跳过漫长的翻译。
8. 按 **Play**。

应用 Home 页面上的 **How to get your game files onto the phone** 也有相同的步骤。

#### 触控操作和手柄

- 未连接手柄时会显示**触控按键**。屏幕上的菜单按钮会打开触控菜单：**Hide touch controls**、**Edit layout**（拖动按键来移动它；点按一个按键，然后选择 **Smaller** 或 **Bigger**）、**Exit to Recompia** 和 **Back to the game**。
- 在屏幕空白处拖动即可转动视角；在那里短按会传给游戏。灵敏度和反转轴位于应用的 **Settings** 中的 **Touch camera**。
- 支持通过 USB 或蓝牙连接的**手柄**。连接手柄时触控按键会隐藏（**Settings** 中的 **Hide when a controller is connected**）。
- 不透明度、大小、振动和 **Reset touch layout** 位于应用的 **Settings** 中的 **Touch controls**。

#### Android 设置

应用的 **Settings** 包含显示、触控按键、游戏玩法、Link Play 和 GPU 驱动设置；大多数会在下次启动游戏时生效。在游戏中，暂停菜单的 **Settings** 在 **Display** 选项卡中有以下设置：

| 设置 | 作用 |
|---|---|
| **Frame Rate Limit** | 每个选项都是屏幕刷新次数的整数倍。默认 30；更低的值运行更凉爽、更稳定。 |
| **Resolution** | 3D 画面的分辨率，每边为屏幕的 15% 至 100%。菜单和文字保持清晰。立即生效：如果手机发热或变慢，请调低。首次启动时会选择适合手机 GPU 的屏幕比例。 |
| **Dynamic Resolution** | 默认关闭。GPU 跟不上时，将分辨率降到上面设置的值以下，之后再升回该值。**Dynamic Resolution Mode** 可选择 **GPU Time** 或 **Heat**（还会将其保持在不让手机降频的水平以下）。 |

在 **Performance** 选项卡中：

| 设置 | 作用 |
|---|---|
| **Upscaler** | **SGSR**（Snapdragon Game Super Resolution，默认且推荐的选项：开销更低、更稳定）会锐化放大后的 3D 画面。**SGSR 2** 会在多帧之间构建更多细节，但开销更大，移动时可能略有闪烁；使用低内存配置的手机不提供此选项。**Off** 会直接拉伸画面。无论哪种方式，菜单都保持清晰。保存设置时生效。 |
| **Sharpness** | SGSR 2 对画面的锐化程度（SGSR 不使用此项）。立即生效。 |

## 模组与翻译

你可以在不改动游戏转储的情况下，将包含替换文件的文件夹（文本或纹理模组、翻译）叠加到游戏中：使用 **Settings > Game > Mods**，或在 `pkp.ini` 的 `[fs]` 下设置 `romfs_mod`。本项目不附带任何内容，请从模组作者处获取模组。

你选择的文件夹必须与游戏自身的 `romfs` 结构相同：从顶层开始，文件和文件夹保持一致。同路径的文件会替换游戏文件，文件夹会合并，仅存在于模组中的文件也会被使用。

```text
MyMod/                       <- choose this folder in Settings > Game > Mods
├── LD_C0_R.BIN              <- same path as in the game's romfs
├── LI_C0_R.IDX
└── motor_asset_re/
    └── ...
```

如果下载内容带有外层文件夹（例如 `2.0.1/romfs/...`），请选择内层的 `romfs` 文件夹，也就是包含 `LD_C0_R.BIN` 的那个文件夹，不要选择外层文件夹。如果文件夹层级不正确，`pkp.log` 会指出模组中没有任何文件替换游戏文件。不支持替换包含着色器的文件的模组。

### 模组与翻译（巴西葡萄牙语）

你可以在不改动游戏转储的情况下，将包含替换文件的文件夹（文本或纹理模组、翻译）叠加到游戏中：使用 **Settings > Game > Mods**，或在 `pkp.ini` 的 `[fs]` 下设置 `romfs_mod`。本项目不附带任何模组，请从模组作者处获取。

所选文件夹必须与游戏的 `romfs` 文件夹结构相同：从最高层级开始，文件和文件夹保持一致。其中的文件会替换游戏中同路径的文件，文件夹会合并，仅存在于模组中的文件也会被使用。

如果下载内容带有外层文件夹（例如 `2.0.1/romfs/...`），请选择内层的 `romfs` 文件夹，也就是包含 `LD_C0_R.BIN` 的那个文件夹，不要选择外层文件夹。如果文件夹层级不正确，`pkp.log` 会指出模组中没有任何文件替换游戏文件。不支持替换包含着色器的文件的模组。

## 从旧版本更新

你的存档、设置和着色器都会保留。

**从 0.7.5 开始：** 在 Home 页面按 **Update**（更新），或前往 Settings > About。启动器会下载新版本、进行检查、替换自身文件并重新启动。如果新版本更改了游戏代码，启动器会先使用新版本自带的工具，在你现有的游戏程序（`pkp.exe`）旁边构建新的游戏程序。根据你的电脑性能，这需要几分钟到一小时不等，期间你可以一直继续游玩：Home 页面会显示进度，游戏关闭后才会安装更新。在此之前按 **Cancel** 可停止更新，不会更改任何内容；下次按 **Update** 时会从停止的地方继续。

**从 0.7.0 或更早版本：** 从[最新发布版本](https://github.com/Dittobyte/Recompia/releases/latest)下载新的 zip（Windows）或 `Recompia-<version>-linux-x86_64.tar.gz`（Linux），关闭游戏和启动器，然后解压到现有安装的同一文件夹中覆盖。包中不含存档、设置、着色器缓存或游戏文件，因此不会替换你的这些内容。

**如果更新后 Home 显示 Finish update：** 该版本更改了游戏代码，但更新前无法构建（手动解压的安装，或在 Settings 中选择了较旧的版本），因此启动器会根据你的游戏文件重新构建游戏程序（`pkp.exe`）。如果你之前跳过了此类版本，之后手动更新时也会出现这一过程。根据你的电脑性能，这需要几分钟到一小时不等，着色器和存档都会保留。这不是漫长的首次设置：只有发布说明要求时才会重新翻译着色器，而且只处理有变化的着色器。在新的 `pkp.exe` 准备就绪前，旧文件会保留。

如需备份，请先将 `save` 文件夹复制到其他位置。较新版本写入的存档可能无法在较旧版本中读取。

**Android：** 从[最新发布版本](https://github.com/Dittobyte/Recompia/releases/latest)下载新的 `Recompia-<version>-android-arm64.apk`，并覆盖安装到现有应用上。你在 `/sdcard/Recompia` 中的存档、设置、着色器缓存和游戏文件都会保留。如果之后 Home 显示 **Set up again**，请按下它：新版本带来了新的构建工具或新的游戏接口，因此游戏会在手机上重新构建。存档和着色器会保留。

**Android，从 0.16 更新到 0.17.0：** 0.17.0 APK 的 Android 版本号低于 0.16 的 APK，因此 Android 拒绝将其覆盖安装到 0.16 上。在包含修复（[#898](https://github.com/Dittobyte/Recompia/pull/898)）的版本发布之前，请先卸载 0.16，再安装 0.17.0。卸载会保留 `/sdcard/Recompia` 中的所有内容（存档、着色器缓存、`pkp.ini` 和 `controls.ini`），但会删除应用内部保存的内容：已构建的游戏、GPU 驱动以及触控按键的设置和布局。之后设置流程会重新运行：允许存储访问、选择游戏文件、重新构建游戏，在 Adreno 手机上还要重新选择 Turnip 驱动。着色器缓存会在原位置被找到。

## 一起游玩

Link Play 可让多名玩家来到同一座岛屿。与使用上游项目的玩家跨平台联机时，游戏版本须为 **2.0.1**。游戏版本为 1.0.5 的玩家无法加入。

**有什么变化。** Link Play 现在使用上游项目的合作协议。它不能与本移植版早期的 Link Play 构建配合使用，因此每个人都需要更新到此版本。

**每位玩家都需要自己的存档。** 复制他人的存档后，该副本无法与原存档一起加入。

**设置方法。** 在启动器中打开 **Link Play**，然后选择一项：

| 选项 | 用途 |
|---|---|
| Off | 不使用 Link Play。 |
| Same network | 默认选项。在同一 Wi-Fi 或网络中自动找到主机。如果找不到，请在 **Join directly** 中输入主机地址，例如 `192.0.2.10`（显示在主机页面的 **This PC** 下）。 |
| Internet | 通过互联网游玩。每个房间都会出现在游戏的 **Visit a Friend** 列表中：无需房间代码，也无需转发端口。 |

更改会在下次启动游戏时生效。

**在游戏中**，打开第一座房子里的电脑，然后选择 **Link Play**（在 Withered Wasteland 达到 Environment Level 2 后解锁），再选择 **Local connection**。（**Online connection** 是 Nintendo 自己的服务，在这里不可用。）主机选择 **Invite Others to Visit**，其他玩家选择 **Visit a Friend**。

**同一网络。** 每个人都选择 **Same network**。Steam Deck 和其他 Proton 或 Linux 设备无论位于哪个网络，都能发现主机，也能被主机发现。咖啡馆、酒店和访客 Wi-Fi 通常会隔离设备：在这些网络中，请改用互联网游玩。

**通过互联网。** 每个人都选择 **Internet**。无需转发端口，也无需输入代码：启动器使用本项目的公共中继服务器，其中的每个房间都会出现在游戏的 **Visit a Friend** 列表中。如需私人房间，请在游戏询问是否设置 **Link Code** 时选择是：只有输入该代码的玩家才能加入。使用你自己的中继服务器或转发端口的选项位于 **Advanced** 下；任何上游项目的合作中继服务器也都可以在那里使用，在服务器上运行 `Recompia --host` 即可自行运行一个。**[Link Play 指南](../link-play.md)** 提供了操作步骤以及无法连接时的检查事项；[完整的多人游戏页面](../multiplayer/README.md) 介绍了中继服务器和端口。中继服务器不会加密游戏流量。

**端口和防火墙。** 首次作为主机时，Windows 防火墙会询问是否允许 `pkp.exe`：请允许 **Private networks**。你的网络也必须设为专用网络（Settings、Network & internet、你的连接、Network profile type：**Private**）。

| 端口 | 使用方 | 协议 |
|---|---|---|
| 47600 | 主机 | TCP 和 UDP |
| 47610 | 中继服务器 | TCP，以及用于快速路径的 UDP |

**Interact everywhere（实验性，默认关闭）。** 在剧情区域中，游戏会让访客进入 Spectator Mode。**Interact everywhere** 允许访客在这些区域使用动作和物品，以及拾取、放置和建造。每位玩家都必须将此开关设为相同状态，否则不会列出主机。

Link Play：加入游戏和一起走动已可用。工作原理和 `pkp.ini` 设置项请参阅 [docs/multiplayer](../multiplayer/README.md)。

**在 Android 上。** Link Play 位于应用的 **Settings** 中的 **Link Play**：选择 **Same network** 或 **Internet**，与上文相同。手机不会自动发现网络中的主机：要在同一网络中拜访，请输入主机地址；要作为主机，请将其留空。通过互联网游玩时，中继服务器上的房间会出现在 **Visit a Friend** 中。更改会在下次启动游戏时生效。合作模式是 Home 页面上的 **Recompia: Co-op** 卡片：使用合作存档创建者分享的邀请加入（短代码 `XXX-XXX`，有效期 6 小时，或较长的 `PKCOOP1.` 文本），也可以在那里创建新的合作存档并邀请他人。所有人都通过该存档的中继服务器游玩，新的合作存档会从新游戏开始。

## 常见问题

- **首次启动时窗口黑屏，或游戏严重卡顿。** 游戏会在运行时生成一些着色器。启动器会在每次启动前以及退出后翻译此前见过的着色器，因此最初几次运行会比较卡顿，之后会改善。请给它一分钟并继续游玩。如果设置中途停止，请打开 **Game files** 并按 **Set up** 继续。已完成的工作会保留。
- **Windows 提示 "Smart App Control blocked" 了启动器、设置程序或游戏。** Smart App Control 只运行带有数字签名或 Microsoft 已知的程序，而且没有 **Run anyway** 按钮。游戏（`pkp.exe`）是在设置期间在你自己的电脑上编译的，因此永远不可能带有签名。请关闭 Smart App Control：**Windows Security**、**App & browser control**、**Smart App Control settings**、**Off**。在某些 Windows 11 版本上，关闭后必须重置 Windows 才能重新开启，因此确认前请先阅读 Windows 自己的提示。然后再次运行 `Recompia.exe`，如果设置已停止，请按 **Set up**。
- **启动器提示游戏文件来自旧版本，或缺少更新。** 此版本需要 2.0.1a。安装更新后重新转储游戏。仅有基础游戏不够。
- **启动器提示未找到可用的游戏文件，或 Set up 提示文件不匹配。** 请选择包含 `base` 和 `updates` 的文件夹（例如 `Game_v2.0.1a`）。两者都需要包含 `exefs`（`main`、`sdk`、`subsdk0`、`rtld`、`main.npdm`）和 `romfs`。不匹配的文件已经损坏，请重新转储或重新复制。
- **启动器提示游戏数据（romfs）不完整，或游戏启动时关闭并显示 "pkp.exe exited with code 4"。** 你的转储工具写入更新的 `romfs` 时，没有将基础游戏的文件放在其中（更新只包含它更改的文件）。请将基础游戏保留在同一转储中（`base` 与 `updates` 并列，各自包含 `exefs` 和 `romfs`），并选择同时包含这两者的文件夹：启动器会自动从 `base` 添加缺失文件。然后再按一次 **Set up**。否则，请重新转储游戏，并将更新合并到基础游戏中。
- **启动器提示转储以文本模式复制。** 你使用 FTP 的文本模式进行了复制，这会损坏 `main`、`sdk` 和 `subsdk0`。请将传输类型设为 **Binary**，重新复制 `exefs` 和 `romfs` 文件夹（FileZilla：Transfer、Transfer type、Binary）。
- **你的转储只有一个文件**（`.nsp`、`.xci`）。启动器接受文件夹形式或 `.nup` 或 `.nx` 包形式的游戏（`.nx` 须由解压后的文件或 `.nup` 制作，不能直接由 `.nsp` 或 `.xci` 制作）。请用你的转储工具将 `.nsp` 或 `.xci` 解压为文件夹。
- **设置因文件无法打开或删除而报错停止。** 请将文件夹放在简单路径下，例如 `C:\Recompia`，不要放在 OneDrive 同步的文件夹中。杀毒软件可能正在扫描构建中的文件：等待扫描完成，或允许该文件夹。**Open setup log** 会显示停止的位置。
- **Set up 在开始前发出警告。** 它会先检查可用磁盘空间（使用打包的着色器文件，即默认设置，约需 14 GB；使用松散文件约需 31 GB）、Vulkan、内存和处理器。如果你使用 Intel 第 13 或第 14 代台式机 CPU，请在设置前更新 BIOS：没有 Intel 的修复，这些 CPU 在长时间满载时可能崩溃。如果构建期间电脑过热或难以使用，请勾选 **Use fewer cores**。
- **帧率低或画面模糊。** 画面尺寸在游戏启动时确定，即当时窗口或屏幕的尺寸（**Settings**、**Display**）。
  - 在 4K 屏幕上以 **Borderless** 启动，游戏就会以 4K 绘制。这会给硬件带来很大负担，请降低 **Render scale**。
  - 以 **Windowed**（默认 1280x720）启动后按 Alt+Enter，画面仍保持 720p，只会放大显示。请在按 **Play** 前设置 **Window mode**。
  - 将 **Frame rate limit** 设为屏幕能够显示的值。
- **Link Play：访客找不到主机。** 选择 **Visit by address** 并输入主机地址（主机的 Link Play 页面会显示该地址）。确认主机已启动游戏并选择 **Invite Others to Visit**，Windows 防火墙允许 `pkp.exe` 使用专用网络，并且网络已设为专用。咖啡馆、酒店和访客 Wi-Fi 的设备隔离会阻止所有人进行 LAN 游玩：请使用 **Internet**，通过中继服务器和房间代码连接。通过互联网游玩时，请检查中继地址和房间代码。Link Play 页面的更改会在下次启动游戏时生效。
- **Link Play：连接被拒绝。** 玩家之间的内容不匹配。每个人都需要游戏 2.0.1、相同的发布版本（跨平台联机时使用上游项目）、相同的模组，并且 **Interact everywhere** 开关状态相同。
- **Link Play：拜访时出现 "Communication error" (9005)。** 你们正在使用同一存档的副本，因此拥有相同的玩家 ID。每位玩家都需要自己的存档。
- **未检测到手柄。** 在游戏中按 F1，查看 Controls 页面的 **Gamepad** 一行。如果游戏未检测到手柄，会显示 "No gamepad open"。请在按 **Play** 前连接手柄，然后尝试其他线缆或接口。关闭可能正在占用该手柄的其他程序。

**在 Android 上：**
- **使用 Adreno GPU 的手机画面黑屏。** 手机自带的驱动在此游戏中会显示黑屏。在应用的 **Settings** 中的 **GPU driver** 里，选择 **Use the included Turnip driver**。如果使用某个驱动后游戏无法启动或画面异常，请在那里选择 **Use the system driver**。
- **手机内存少于 12 GB**（例如 8 GB 的手机）。应用会使用低内存配置：更低的阴影和纹理尺寸、更低的输出分辨率，并使用约 5 GB 的可用存储空间作为游戏的额外内存。如果可用存储空间少于此值，游戏会在没有额外内存的情况下启动，可能不太稳定：Home 页面会提示这一点。为获得最佳效果，请释放一些空间。
- **手机发热，或一段时间后帧率下降。** 手机发热时会降速。在游戏的 **Settings** 中的 **Display** 里降低 **Resolution**（立即生效），或降低 **Frame Rate Limit**。将帧率计数器的 **Counter Detail** 设为 **Full**，即可查看手机温度以及 GPU 和 CPU 的负载。构建和着色器翻译是耗时较长的繁重任务：请保持手机接通电源并放在凉爽处，手机变热时应用会发出警告。
- **系统关闭应用后构建停止了。** 打开应用并按 **Continue building**：已完成的工作会保留。
- **游戏文件无法使用。** **Game files** 步骤会说明问题所在（旧版本、缺少更新的基础游戏、复制时文件缺失或损坏）以及解决方法，与电脑版相同。`base` 或 `updates/<version>` 都需要包含 `exefs` 和 `romfs`。**Show details** 会列出缺少的内容。

如果以上都不是你的问题，请参阅[报告问题](#reporting-problems)。

## 存档、日志和设置的位置

这些内容都位于游戏文件夹，即包含 `Recompia.exe` 和 `pkp.exe` 的文件夹，除非你在 **Settings** 的 **Game folder** 中选择了其他位置。

| 内容 | 位置 |
|---|---|
| 存档 | `save`（**Settings** 可通过 **Save folder** 指向其他位置） |
| 设置 | `pkp.ini` 和 `controls.ini`（游戏中的 F1 会写入 `controls.ini`） |
| 日志 | `pkp.log`，每次从启动器启动时写入。崩溃时还会写入 `pkp_crash.txt`、`pkp_freeze.txt` 或 `pkp_fatal.txt`。 |
| 已翻译的着色器 | `shader_cache`（约 26 GB） |
| 构建文件 | `build`（设置过程的工作文件夹） |
| 解压的 `.nup` 或 `.nx` | `nup_dump`，如果你选择了 `.nup` 或 `.nx`（其附加内容（如有）在 `nup_dump/aoc` 中） |
| 启动器设置 | `%APPDATA%\org.pkp-recomp.launcher\launcher.json`（你的转储文件夹和游戏文件夹） |

**在 Android 上**，它们位于 `/sdcard/Recompia`（手机的内部存储，`Recompia` 文件夹）：

| 内容 | 位置 |
|---|---|
| 存档 | `save`（合作存档在 `coop-saves` 中）。Home 页面上的 **Saves** 可将存档导出为 zip 供电脑使用，或导入来自电脑的存档文件夹 zip。 |
| 设置 | `pkp.ini` 和 `controls.ini`。触控按键的设置和布局保存在应用内部。 |
| 日志 | `logs/pkp.log`。Home 页面上的 **Logs** 会显示最新日志，并可分享或保存副本。 |
| 已翻译的着色器 | `shader_cache`（约 6.6 GB） |
| 构建文件 | `build`（构建过程的工作文件夹） |
| 复制的游戏文件 | `dump`，仅当应用复制了你的转储时才有。否则会在原位置读取你的转储。 |
| 已构建的游戏和 GPU 驱动 | 位于应用内部，卸载应用时会被删除 |

Home 页面上的 **Storage** 会显示每项占用的空间，并可删除构建文件、着色器缓存、复制的转储或存档。

绝不要在问题反馈中附加游戏文件、`build` 或 `shader_cache` 文件夹，或存档。只提供 `pkp.log` 即可。
