# Shader archive screenshots

For the release notes of the packed shader files (PR #240). Taken from the launcher's dev mock
(`npm run dev`, `?s=ready`, `?s=packed`, `?s=preflight-warn&page=setup`), so every size in them is a stand-in, not a
measurement: use the numbers `setup.log` reports from a real install in the notes.

| File | Shows |
| --- | --- |
| `1-free-up-space-prompt.webp` | The question at launcher start while loose shader files are left |
| `2-packing-on-home.webp` | Packing in progress: Home task box with Stop, sidebar task pill |
| `3-packed-toast.webp` | Finished, with the space freed |
| `4-settings-loose.webp` | Settings > Game > Shader files before packing |
| `5-settings-packed.webp` | The same after packing, with the way back |
| `6-setup-packed-on.webp` | Set up page for a new install: packed (default), needs about 14 GB free |
| `7-setup-packed-off.webp` | The same with loose files: about 31 GB free |
