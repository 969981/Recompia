Pokopia PC @VERSION@

1. Run PokopiaLauncher.exe and pick your dump folder (base/ and updates/<version>/, each with exefs/ and romfs/). Version 2.0.1a is required.
2. Press Set up. It builds pkp.exe and the shader cache on this PC. You can pause and continue later.
3. Press Play.
