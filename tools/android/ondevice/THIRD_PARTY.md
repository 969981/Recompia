# On-device toolchain: third-party components

Everything the APK carries for the on-device game build (packed by `tools/android/ondevice/package.sh` into
`lib/arm64-v8a/libpython_exec.so`, `lib/arm64-v8a/libllvm_exec.so` and `assets/recompia-toolchain.tar.xz`). None of it is
stored in this repository: the scripts beside this file fetch and build it. For the app's About screen, show each name,
version, license and source URL; the full license texts are in the source archives named here.

Notes for distribution:
- Apache-2.0 (LLVM, OpenSSL) requires shipping the license text and any NOTICE files: the About screen should link or embed
  `LICENSE.TXT` from llvm-project and OpenSSL's `LICENSE.txt`; the LLVM exception waives the attribution requirement for code
  compiled by clang into the game library (builtins, libunwind, libc++).
- PSF-2.0 requires the PSF copyright notice to be retained (`LICENSE` in the CPython source).
- BSD licenses (Capstone, python-lz4, LZ4, bionic) require their copyright notices in the documentation shipped with the binary.
