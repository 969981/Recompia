# Legal

**This repository contains no game code, no game data, no keys and no copyrighted assets from the game.** It is a runtime, a recompiler and tools, all written for this project or taken from open-source projects under their licences. You must own a legitimate copy of the game and supply files you extracted yourself from your own copy. This project does not explain how to get them. It does not ship, host, link to or help with game dumps, keys or firmware.

## Don't share what you build

The game code that runs on your PC is generated on your PC from your files, and it stays there. Do not upload or share your dump, the generated code (`work\`), the game folder (`game\`) or a `pkp.exe` you built. They contain material derived from the game, and the owners' rights apply to it.

## No piracy

We do not support piracy. Issues involving pirated or modified copies are closed without help. Never post game files, keys, firmware, generated code or anything extracted from the game in an issue, pull request or discussion. We delete such posts.

## No keys and no circumvention

This project contains no decryption keys and no code that decrypts protected console content, and it doesn't read keys from any device or other software. It only reads files you have already extracted and prepared yourself.

## Interoperability

The runtime reimplements system interfaces so a copy of the game the user owns can run on a PC. It contains no code from Nintendo's system software or SDK. Facts about how the game and the system interface with each other (function addresses, structure layouts, command numbers) are recorded only as far as needed for that purpose.
